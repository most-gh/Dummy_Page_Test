# MotherApp Clienteling App GEO mockup

This is a self-contained, responsive GitHub Pages source package for a GEO-friendly rewrite of MotherApp's Clienteling App product page.

## Deploy to GitHub Pages

1. Create a new folder named `clienteling-app-geo` at the repository root.
2. Copy the contents of this package into that folder, preserving `assets/`, `css/` and `js/`.
3. Commit and push the folder to the branch used by GitHub Pages.
4. The preview URL will be `https://<account>.github.io/<repository>/clienteling-app-geo/`.

## Package structure

```
clienteling-app-geo/
├── index.html
├── README.md
├── assets/
│   └── clienteling-dashboard.svg
├── css/
│   └── styles.css
└── js/
    └── main.js
```

## Before publishing to motherapp.com

- Replace the proof-module placeholder only with approved, attributable customer evidence.
- Keep `Book a demo` as the main CTA, or replace every CTA consistently with the approved alternative.
- Verify final tracking and contact form behaviour in the target CMS.
- Review legal, accessibility, privacy and brand requirements with the website owner.
